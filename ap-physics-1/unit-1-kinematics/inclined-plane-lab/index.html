Calculate velocity from the raw data: v = Δx / Δt. Use two nearby position-time points near the beginning of a run for vᵢ and two nearby points near the end for v_f. Then calculate Δt = t_f − tᵢ, Δv = v_f − vᵢ, and a = Δv / Δt.

Student Task

  1. Select the incline angle, starting position, data interval, and data type for Trial 1.
  2. Choose Position vs. Time if you want to calculate velocity from position data, or choose Velocity vs. Time to collect velocity directly.
  3. Release the cart and record the needed initial and final values.
  4. Record tᵢ, t_f, vᵢ, and v_f in your lab data chart. If using position data, calculate vᵢ and v_f from nearby points first.
  5. Calculate Δt, Δv, and acceleration.
  6. Repeat until you have completed five trials.
